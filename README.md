# CV Builder App

A simple and intuitive CV Builder Android application built using **Android Studio** and **Java**. The app helps users create a professional-looking CV by entering personal, academic, and professional details across multiple screens. It uses **`ActivityResultLauncher`** to handle data input across activities.


##  Features

- Input personal information (name, summary, email, phone, url)
- Add academic background
- Record work experience
- List certifications
- Preview and share the CV
